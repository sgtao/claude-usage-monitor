# 配り方・入れ方ガイド（非エンジニア向け）

`usage-monitor`（USAGE MONITOR）を、ほかの人に届けて使ってもらうための手順書です。

- **配る人**（このリポジトリの持ち主）→ [パート A](#パートa配る人がやること)
- **使う人**（受け取った人）→ [パート B](#パートb使う人がやること)
- うまくいかないとき → [パート C](#パートcうまくいかないとき)
- 気になること（安全性・更新）→ [パート D](#パートdよくある疑問)
- **オフにしたい・削除したい** → [パート E](#パートeオフにする削除する)

-----

## 0. まず全体像（3分で読める版）

### これは何？

Claude Code の入力欄の上に「使った量のメーター」を出す、**小さな追加機能（プラグイン）**です。

```
╭──────────────────────────────────────────────────────────────╮
│ USAGE MONITOR           ■ account ■ this session ░ free   [x] │
│ 5h [██████░░░░░░░░░░░░░░░░░░] 12.0% +3.1% ⟳ 4h51m             │
│ 7d [█░░░░░░░░░░░░░░░░░░░░░░░]  4.0% +0.4% ⟳ 4d19h             │
│ ses 445.1k tok │ in 16.3k out 3.7k cache 425.0k │ cost $1.85  │
╰──────────────────────────────────────────────────────────────╯
```

### どうやって届ける？（スマホのアプリに例えると）

| スマホのアプリ | このプラグイン | 
| --- | --- |
| アプリ本体 | `usage-monitor` |
| アプリストア | GitHub 上の置き場所（リポジトリ `claude-usage-monitor`）。専門用語では「マーケットプレイス」 |
| 「インストール」ボタン | Claude Code に **1 行のコマンド**を入力すること |

つまり、配る人は「置き場所を用意して、コマンドを 1 行教える」だけ。使う人は「そのコマンドを貼り付けて、`y` と Enter を押す」だけです。

### 方法は 3 つ（迷ったら ① ）

| | 方法 | 向いている場面 | 使う人の手間 |
| --- | --- | --- | --- |
| ① | **GitHub で公開**（おすすめ） | 不特定多数・チームに広く配る | コマンド 1 行 |
| ② | **ファイル（zip）で渡す** | GitHub を使わない・社内だけで共有 | 解凍 + コマンド 2 行 |
| ③ | **お試しで 1 回だけ使う** | 入れる前に動きを見たい | 起動時にオプションを付ける（そのセッションだけ） |

## パート A：配る人がやること

### A-1. ① GitHub で公開する（おすすめ）

#### 準備するもの

- GitHub のアカウント（無料。<https://github.com> で作成）
- このフォルダ（`1014_claude-usage-monitor-mod`）。すでに `git` で管理済みです

#### 手順

1. **GitHub に空のリポジトリを作る**
   1. GitHub にログインし、右上の「＋」→「New repository」を押します。
   2. **Repository name** に `claude-usage-monitor` と入力します（この名前が配布用の名前になります）。
   3. **Public**（誰でも見られる）か **Private**（招待した人だけ）を選びます。広く配るなら Public です。
   4. 「Add a README file」「Add .gitignore」「Choose a license」は**すべてオフ**のままにします（手元にもう入っているため）。
   5. 「Create repository」を押します。
2. **手元のフォルダを GitHub に送る**（ターミナルで実行）。`<あなたのGitHubユーザー名>` は自分の名前に置き換えます。

   ```bash
   cd /Users/sgtao/idea/2026_ideas/1010_develop-with-claude/1014_claude-usage-monitor-mod
   git branch -M main
   git remote add origin git@github.com:<あなたのGitHubユーザー名>/claude-usage-monitor.git
   git push -u origin main
   ```

   うまくいかないときは、`git@github.com:` の代わりに `https://github.com/` 形式でも送れます（パート C 参照）。
3. **ブラウザでリポジトリを開いて確認する**：`README.md` が表示され、`.claude-plugin` フォルダがあれば成功です。
4. **使う人にこの 1 行を伝える**（`<owner>` はあなたの GitHub ユーザー名）：

   ```
   /plugin install usage-monitor --marketplace <owner>/claude-usage-monitor
   ```

   あわせて、このガイドの [パート B](#パートb使う人がやること) へのリンク（GitHub 上の `docs/share-and-install-guide.md`）を送ると親切です。

#### Private にした場合の注意

- 使う人を GitHub の「Settings → Collaborators」で招待しておく必要があります。
- 使う人のパソコンで、GitHub にログインできる状態（git の認証）が必要になることがあります。非エンジニアには少しハードルが高いので、**広く配るなら Public がおすすめ**です。

### A-2. ② ファイル（zip）で渡す

GitHub を使わず、**zip ファイル 1 つ**で渡す方法です。社内だけ・知り合いだけに渡したいときに向いています。

> **しくみ**：zip の中身は「プラグイン本体」と「配布元の目録（`.claude-plugin/marketplace.json`）」が入った 1 つのフォルダです。受け取った人が、そのフォルダを Claude Code に「ここが配布元です」と登録するだけで、GitHub と同じように入れられます。

#### 手順

1. **変更を確定（コミット）しておく。** zip には「確定済みの内容」だけが入ります。未確定の変更があると、zip に入りません。ターミナルで次を実行し、何も表示されなければ OK です。

   ```bash
   cd /Users/sgtao/idea/2026_ideas/1010_develop-with-claude/1014_claude-usage-monitor-mod
   git status --short
   ```

   何か表示されたら（未確定の変更あり）、次で確定します。

   ```bash
   git add -A
   git commit -m "配布用に更新"
   ```
2. **zip を作る。** 同じフォルダで次の 1 行を実行します。デスクトップに `claude-usage-monitor.zip` ができます。

   ```bash
   git archive --format=zip --prefix=claude-usage-monitor/ -o ~/Desktop/claude-usage-monitor.zip HEAD
   ```

   - この方法だと、**余計なもの（履歴・作者のメールアドレスなど）が入らず**、必要なファイルだけが 1 つのフォルダ `claude-usage-monitor/` にまとまります。
   - Finder の右クリック →「圧縮」でも作れますが、隠しフォルダ `.git`（これまでの変更履歴）まで入ってしまうので、**上のコマンドをおすすめ**します。
3. **zip の中身を確認する。** 次を実行して、一覧に **`.claude-plugin/plugin.json`** と **`.claude-plugin/marketplace.json`** が入っていれば OK です。

   ```bash
   unzip -l ~/Desktop/claude-usage-monitor.zip
   ```

   > ⚠️ `.claude-plugin` は**隠しフォルダ**（先頭が「.」）なので、Finder では見えません。**ファイルを手作業で選んで zip にすると、これが抜けやすい**ので注意してください。抜けると、受け取った人は「Marketplace file not found」で入れられません。
4. **zip を渡す。** メール添付・Slack・Google ドライブ・AirDrop など、普段使っている手段で構いません。
5. **次の「お知らせ文」を一緒に送る。**（丸ごとコピーして使えます）

   ```
   Claude Code の使用量メーター「USAGE MONITOR」をお送りします。

   ■ 入れ方（約 3 分）
   1. 添付の claude-usage-monitor.zip を解凍し、できた「claude-usage-monitor」フォルダを
      ホームフォルダ（Mac なら ユーザー名のフォルダ）に置いてください。
      ※ このフォルダは入れたあとも消したり動かしたりしないでください。
   2. ターミナルを開き、次の 2 行を 1 行ずつ貼り付けて Enter を押してください。
        claude plugin marketplace add ~/claude-usage-monitor
        claude plugin install usage-monitor@claude-usage-monitor
   3. 「Successfully installed」と出れば完了です。Claude Code を起動して、
      何か話しかけると、入力欄の上にメーターが出ます。

   くわしい手順・困ったとき・消し方は、同梱の README.md と docs/share-and-install-guide.md を見てください。
   ```

   > Windows の人には、2 行目の `~/claude-usage-monitor` を、**フォルダのフルパス**（例：`C:\Users\あなた\claude-usage-monitor`）に置き換えるよう伝えてください。

#### 新しい版を渡したくなったら

1. 直したあと、`.claude-plugin/plugin.json` の `"version"`（例：`0.2.0` → `0.2.1`）を上げて、確定（コミット）する。
2. もう一度 A-2 の手順 2 で zip を作って渡す。
3. 受け取る人には、[B-2 の「新しい版をもらったとき」](#新しい版をもらったとき)を伝える。

### A-3. ③ お試し（入れずに 1 回だけ試す）

インストールせず、そのセッションだけ動かせます。「入れる前に見せたい」ときに使います。

```bash
claude --plugin-dir /フォルダの場所/1014_claude-usage-monitor-mod
```

終了すると元に戻ります（何も残りません）。

### A-4. 配った後に直したくなったら

1. このフォルダでファイルを直す。
2. `git add -A` → `git commit -m "変更内容"` → `git push` で GitHub に送る。
3. 使う人に「更新して」と伝える（手順は [D-3](#d-3-更新したい)）。

## パート B：使う人がやること

### B-0. 始める前に確認すること

| 確認すること | 説明 |
| --- | --- |
| **Claude Code が入っている** | ターミナル版の Claude Code が必要です。まだなら、Claude Code の公式ドキュメントの手順で先に入れてください。 |
| **ログイン済み** | ターミナルで `claude` と打って、普通に会話できる状態。 |
| **（メーターを見たいなら）サブスクリプション** | 5h / 7d のメーターは、Pro / Max などのサブスクリプションで使っているときに出ます。API キーだけで使っている場合は、メーターの代わりに「waiting for the first rate-limit reading…」と出ますが、下の `ses`（このセッションのトークン量・費用）は表示されます。 |

> **ターミナルとは？** コマンド（文字の命令）を打つ黒い画面のことです。
> - **Mac**：「Spotlight 検索（⌘ + スペース）」で「ターミナル」と入力して Enter。
> - **Windows**：スタートメニューで「PowerShell」と入力して Enter。

### B-1. ① GitHub の公開版を入れる（いちばん簡単）

所要時間：約 1 分。

1. **ターミナルを開き、`claude` と入力して Enter。** Claude Code が起動します。
2. **次の 1 行を貼り付けて Enter。**（`<owner>` は配る人に教えてもらった名前に置き換え）

   ```
   /plugin install usage-monitor --marketplace <owner>/claude-usage-monitor
   ```
3. **「Add marketplace?」と聞かれたら `y` を押す。**
   （「この配布元を登録していいですか？」という確認です。）
4. **範囲（スコープ）の選択画面では、いちばん上の「user」のまま Enter。**
   - 「user」＝あなたのすべてのプロジェクトで使える設定です。
5. **`Installed usage-monitor. Plugin is now active.` と出たら完了です。**

### B-2. ② zip でもらった人

所要時間：約 3 分。**ターミナルで 2 行貼り付けるだけ**です。

#### 手順

1. **zip を解凍して、「ずっと置いておく場所」に置く。**
   - **Mac**：zip をダブルクリックすると、`claude-usage-monitor` フォルダができます。それを**ホームフォルダ**（Finder の左側にある、自分のユーザー名のフォルダ）に移します。
   - **Windows**：zip を右クリック →「すべて展開」で、自分のユーザーフォルダ（例：`C:\Users\あなたの名前`）に `claude-usage-monitor` を作ります。
   - ⚠️ **このフォルダは、入れたあとも消したり、名前を変えたり、動かしたりしないでください。** プラグインは、このフォルダを見に行って動いています。
2. **ターミナルを開く。**（Mac は「Spotlight 検索（⌘ + スペース）」で「ターミナル」、Windows は「PowerShell」）
   - **Claude Code の画面の中ではなく、普通のターミナルで**実行します。
3. **1 行目を貼り付けて Enter。**（「この配布元を登録します」という意味です）

   Mac（フォルダをホームフォルダに置いた場合）：

   ```bash
   claude plugin marketplace add ~/claude-usage-monitor
   ```

   Windows：`~/claude-usage-monitor` の部分を、フォルダの**フルパス**に置き換えます（例：`C:\Users\あなたの名前\claude-usage-monitor`）。パスは、フォルダを右クリックして「パスのコピー」で取れます。

   > **Mac で、別の場所に置いた場合**：`claude plugin marketplace add ` と入力したあと（最後に半角スペースを入れる）、**Finder からフォルダをターミナルの画面にドラッグ＆ドロップ**すると、パスが自動で入ります。そのまま Enter を押してください。

   **`Successfully added marketplace: claude-usage-monitor`** と出れば成功です。
4. **2 行目を貼り付けて Enter。**（「プラグインを入れます」という意味です）

   ```bash
   claude plugin install usage-monitor@claude-usage-monitor
   ```

   **`Successfully installed plugin: usage-monitor@claude-usage-monitor`** と出れば、インストール完了です。
5. **確認する。** 次を入力して、`usage-monitor` が **`✔ enabled`** になっていれば OK です。`Read from:` の行に、置いたフォルダの場所が表示されます。

   ```bash
   claude plugin list
   ```
6. **Claude Code を起動して、話しかける。** すでに起動していた場合は、`/reload-plugins` と入力するか、一度終了して起動し直します。返事が返ってきたら、入力欄の上に USAGE MONITOR が出ます（[B-3](#b-3-ちゃんと動いているか確認する) へ）。

#### 新しい版をもらったとき

1. 新しい zip を解凍する。
2. **今ある `claude-usage-monitor` フォルダを、新しいフォルダで置き換える。**（同じ場所・同じ名前のまま、中身を上書き）
3. Claude Code で `/reload-plugins` を入力するか、起動し直す。

> 配布元の登録（手順 3）や、インストール（手順 4）は、**やり直す必要はありません。**

#### 消すとき

[パート E](#パートeオフにする削除する) を見てください。最後に、置いた `claude-usage-monitor` フォルダをゴミ箱に入れて完了です。

### B-3. ちゃんと動いているか確認する

1. Claude Code に **何か話しかけて、返事が返ってくるまで待つ。**（例：「こんにちは」）
2. 入力欄の**すぐ上**に、枠線つきの **USAGE MONITOR** が出れば成功です。
   - 最初の返事が来るまでは、メーターが「waiting for the first rate-limit reading…」と出ます。これは正常です。

### B-4. 画面の見方

| 表示 | 意味 |
| --- | --- |
| `5h` | 直近 **5 時間**の使用枠に対する、アカウント全体の使用率 |
| `7d` | 直近 **7 日間**の使用枠に対する、アカウント全体の使用率 |
| バーの **シアン（水色）** | アカウントで使った分（このセッション以外も含む） |
| バーの **マゼンタ（ピンク）** | **今回のセッション**で使った分 |
| バーの `░` | 空き（まだ使える分） |
| `12.0%` | 使用率の合計 |
| `+3.1%` | 今回のセッションで増やした分 |
| `⟳ 4h51m` | 枠がリセットされるまでの時間（4 時間 51 分後） |
| `ses 445.1k tok` | 今回のセッションで使った量の合計（トークン。文字量の単位のようなもの） |
| `in` / `out` / `cache` | 送った量 / 返ってきた量 / 再利用できた量（キャッシュ） |
| `cost $1.85` | 今回のセッションの費用の目安（米ドル） |

> `+x.x%` は「このセッションで最初に見えた使用率」からの増え方です。最初の返事までに使った分は少し含まれず、Claude Code を再起動すると 0 に戻ります。

### B-5. 隠したい・また出したい

- 枠の右上の **`[x]`** を押すと隠れます。
- ふたたび出す／隠すは、入力欄に **`/usage-monitor`** と入力して Enter。

## パート C：うまくいかないとき

| 症状・メッセージ | 原因と対処 |
| --- | --- |
| `Marketplace file not found` | 配布元の指定が違います。`<owner>/claude-usage-monitor` のつづり・ユーザー名を確認。リポジトリが Private で、自分に権限がない可能性もあります。 |
| `Plugin "usage-monitor" not found in marketplace` | プラグイン名のつづり間違い。`usage-monitor`（ハイフン区切り）が正しい名前です。 |
| `/plugin` が使えない／コマンドが無いと言われる | **デスクトップアプリの「Code」タブ**ではこのコマンドが使えません。**ターミナル**で入れてください。ターミナルで user スコープに入れておけば、デスクトップアプリの Code タブでも表示されます。 |
| 入れたのに何も出ない | ① まず 1 回、Claude に話しかけて返事を待つ。② `/usage-monitor` で表示が切り替わるか試す（隠れている可能性）。③ いったん Claude Code を終了して、起動し直す。 |
| メーターが `waiting for the first rate-limit reading…` のまま | サブスクリプション（Pro / Max など）でない場合は、レート制限の値が取れないため出ません。下の `ses` 行は出ます。 |
| zip で入れたのに急に動かなくなった（`claude plugin list` で `failed to load` や `cache-miss` と出る） | 解凍したフォルダを移動・削除・名前変更していませんか？ **元の場所・元の名前に戻せば、また `✔ enabled` に戻ります**（入れ直し不要）。削除してしまった場合は、zip をもう一度解凍して、同じ場所に置いてください。 |
| GitHub に送れない（配る人側）：`Permission denied (publickey)` | SSH の設定がまだのときに出ます。`git@github.com:` の代わりに HTTPS 形式で登録し直します：`git remote set-url origin https://github.com/<ユーザー名>/claude-usage-monitor.git` その後 `git push -u origin main`。 |

それでも解決しない場合は、**表示されたメッセージをそのままコピーして**配る人に送ってください。

## パート D：よくある疑問

### D-1. 安全？ 何をしているの？

このプラグインのソースコード（[`hooks/register.tsx`](../hooks/register.tsx)）で確認できる範囲では、次のことだけをしています。

- Claude Code の画面から、**使用量の数値（トークン量・使用率・費用）を読み取る**
- その数値を**入力欄の上に表示する**
- `/usage-monitor` コマンドを登録する

**していないこと**：インターネットへの通信、ファイルの読み書き、他のプログラムの実行、会話の内容の読み取り・保存。

> 一般に、プラグインは入れた人の環境で動くプログラムです。**知らない人から渡されたプラグインは、中身を確認してから入れる**のが基本です。このプラグインのコードは短いので、気になる人は上のファイルを開いて確認できます。

### D-2. 他のプロジェクト（リポジトリ）でも使える？

使えます。B-1 手順 4 で「user」を選ぶと、自分のすべてのプロジェクトで表示されます。

### D-3. 更新したい

配る人が新しい版を公開したら、ターミナルで次を実行します：

```bash
claude plugin update usage-monitor
```

そのあと、起動中の Claude Code の中で `/reload-plugins` を入力すると反映されます。

### D-4. オフにしたい・削除したい

[パート E](#パートeオフにする削除する) にまとめています。

### D-5. 画面の幅が狭いときは？

バーの長さは、ターミナルの幅に合わせて自動で変わります（最小 10 マス）。あまりに狭いと折り返したり省略されたりします。

### D-6. 費用や使用率の数字はどこまで正確？

Claude Code が画面に出している値（ステータスライン相当）をそのまま使っています。`+x.x%` の「このセッション分」は、最初に取得できた使用率との差から計算した**目安**です。

## パート E：オフにする・削除する

### E-0. どれを選べばいい？

3 つの方法があります。**上ほど軽く、下ほど完全に消えます。** どれも、あとから元に戻せます。

| やりたいこと | 方法 | 戻し方 |
| --- | --- | --- |
| ちょっと邪魔なので、**今だけ隠したい** | [E-1](#e-1-今だけ隠す) 画面の `[x]` を押す | `/usage-monitor` と入力 |
| **しばらく使わない**（でも残しておきたい） | [E-2](#e-2-オフにする無効化残したまま止める) オフにする（無効化） | 「オン」にする（E-2 の最後） |
| **もう使わない**。完全に消したい | [E-3](#e-3-削除するアンインストール) 削除する（アンインストール） | もう一度 B-1 の手順で入れ直す |

> 迷ったら **E-2（オフ）** がおすすめです。消えるわけではないので、後悔しません。

### E-1. 今だけ隠す

操作は 2 通りです。

- 枠の右上の **`[x]`** を押す
- 入力欄に **`/usage-monitor`** と入力して Enter

もう一度 `/usage-monitor` と入力すると、また表示されます（押すたびに「隠す」と「出す」が切り替わります）。

> ⚠️ これは**そのセッション（今開いている Claude Code）だけの設定**です。Claude Code を終了して起動し直すと、また表示されることがあります。ずっと出したくない場合は、E-2 か E-3 をしてください。

### E-2. オフにする（無効化・残したまま止める）

「入ったまま、動かさない」状態にします。いつでも「オン」に戻せます。

#### 手順

1. **ターミナルを開く。**（Mac は「Spotlight 検索（⌘ + スペース）」で「ターミナル」、Windows は「PowerShell」）
   - すでに Claude Code を起動している場合は、**別のターミナルを新しく開く**のが安全です（Claude Code の画面の中ではなく、普通のターミナルで実行します）。
2. **次の 1 行を貼り付けて Enter。**

   ```bash
   claude plugin disable usage-monitor
   ```
3. **「disabled」のような完了メッセージが出たら成功です。**
4. **反映する。** すでに起動している Claude Code では、次のどちらかをします。
   - Claude Code の中で `/reload-plugins` と入力して Enter
   - または、Claude Code を一度終了して、起動し直す
5. **入力欄の上の USAGE MONITOR が消えていれば完了です。**

#### 「オン」に戻すとき

```bash
claude plugin enable usage-monitor
```

そのあと、E-2 の手順 4 と同じように `/reload-plugins` か再起動をします。

### E-3. 削除する（アンインストール）

プラグインを完全に取り除きます。

#### 手順

1. **ターミナルを開く。**（E-2 の手順 1 と同じ）
2. **次の 1 行を貼り付けて Enter。**

   ```bash
   claude plugin uninstall usage-monitor
   ```
3. **完了メッセージが出るのを確認する。**
4. **（おすすめ）入っているか確認する。** 次を入力して、一覧に `usage-monitor` が**出てこなければ**削除できています。

   ```bash
   claude plugin list
   ```
5. **反映する。** 起動中の Claude Code は、`/reload-plugins` を入力するか、終了して起動し直します。
6. **入力欄の上の USAGE MONITOR が消えていれば完了です。**

#### もっときれいに消したい人（任意）

「配布元の登録」も消すと、完全に元の状態に戻ります。**やらなくても、表示は消えます。**

```bash
claude plugin marketplace remove claude-usage-monitor
```

#### zip（フォルダ）で入れた人

上の手順のあと、**解凍したフォルダ**（例：`claude-usage-monitor`）をゴミ箱に入れて構いません。**先に E-3 の手順 2 をしてから**フォルダを消してください（先にフォルダを消すと、削除の手順でエラーが出ることがあります）。

#### 入れるとき「user」以外を選んだ人

B-1 の手順 4 で「user」以外（project / local）を選んだ人は、範囲を指定します。

```bash
claude plugin uninstall usage-monitor --scope project
```

`project` を `local` に変えた版も試せます。「user」で「見つかりません」と出たら、これらを試してください。

#### 削除すると何が残る？

- **ファイルやクラウドに保存しているデータはありません。** このプラグインは使用量の数字を、起動中の画面上で表示するだけです（`claude plugin validate` の結果でも、保存の呼び出しは「セッション中の一時的な状態」だけです）。
- あなたの会話、設定、Claude Code 本体には**影響しません**。

### E-4. 消したあと、また使いたくなったら

[B-1](#b-1-①-github-の公開版を入れるいちばん簡単)（または B-2）の手順で、もう一度入れ直せます。オフ（E-2）にしただけなら `claude plugin enable usage-monitor` で戻せます。

### E-5. うまくいかないとき

| 症状 | 原因と対処 |
| --- | --- |
| 手順のあとも、枠が消えない | 起動中の Claude Code に反映されていません。`/reload-plugins` を入力するか、Claude Code を終了して起動し直してください。 |
| 起動し直しても、枠が出てくる | ① `claude plugin list` で `usage-monitor` が残っていないか確認。② 起動のときに `--plugin-dir` を付けていませんか？ その場合はその設定（ショートカットやエイリアス）を外してください。③ 入れるときに別の範囲（project / local）を選んでいないか → E-3 の「user 以外を選んだ人」を試す。 |
| `not found`（見つかりません）と出る | すでに削除されているか、範囲が違います。`claude plugin list` で状態を確認してください。 |
| `/reload-plugins` が使えない | 一度 Claude Code を終了して、起動し直してください。 |
| 「配布元」を消したら、別のプラグインも消えた | `claude plugin marketplace remove` は、**その配布元から入れたプラグイン**も一緒に外れることがあります。このプラグイン専用の配布元（`claude-usage-monitor`）なので通常は問題ありませんが、ほかのプラグインを同じ配布元から入れている場合は、この操作は**しないでください**。 |

それでも解決しない場合は、**表示されたメッセージをそのままコピーして**配る人に送ってください。
